# ДЗ №1. Изучение средств защиты ОС GNU/Linux

В данном репозитории представлены результаты выполнения домашнего задания по изучению механизмов защиты GNU/Linux.

## Выполнение задания

| Раздел | Подраздел | Выполнение |
| --- | --- | --- |
| 1. Создание пользователя | 1.1. Создание пользователя | Создан обычный пользователь `user1`. Пользователю назначен UID `1234`. Создана группа `students`, пользователь `user1` добавлен в эту группу. С помощью `chage` установлен максимальный срок действия пароля `90` дней, что соответствует смене пароля каждые три месяца. |
| 2. Мониторинг файлов и процессов | 2.1. Мониторинг файлов | Выполнен поиск всех обычных файлов с установленным битом set-UID с помощью `find` и условия `-perm -4000`. Результат поиска сохранён в файл `suid-files.out`. |
| 2. Мониторинг файлов и процессов | 2.2. Мониторинг процессов | Выполнен поиск процессов, у которых эффективный UID равен `0`, а реальный UID относится к диапазону обычных пользователей. Обнаружен процесс `fusermount3` с `RUID=1000` и `EUID=0`. Результат мониторинга сохранён в файл `processes-root-euid.out`. |
| 3. Изучение механизма set-UID | 3.1. Выбор утилиты | Выбрана утилита `touch`. В качестве привилегированной операции выбрано создание файла `/root/setuid-test` пользователем `user1`. Выполнена попытка создания файла обычной утилитой `touch`, подтвердившая отсутствие у `user1` необходимых прав доступа к каталогу `/root`. |
| 3. Изучение механизма set-UID | 3.2. Выполнение привилегированной операции с помощью set-UID | Утилита `/usr/bin/touch` скопирована в `/home/user1/touch-suid`. Владельцем копии является `root`. На файл установлен бит set-UID с помощью `chmod u+s`. После этого от имени `user1` выполнена скопированная утилита `/home/user1/touch-suid`, с помощью которой успешно создан файл `/root/setuid-test`. |
| 4. Изучение механизма привилегий | 4.1. Выбор утилиты | Выбрана утилита `cat`. В качестве привилегированной операции выбрано чтение файла `/etc/shadow` пользователем `user1`. Выполнена попытка чтения файла обычной утилитой `cat`, подтвердившая отсутствие необходимых прав доступа. |
| 4. Изучение механизма привилегий | 4.2. Выполнение привилегированной операции с помощью механизма привилегий | Утилита `/usr/bin/cat` скопирована в `/home/user1/cat-cap`. Копии назначена файловая привилегия `cap_dac_read_search=ep` с помощью `setcap`. После назначения привилегии от имени `user1` выполнена `/home/user1/cat-cap`, с помощью которой успешно прочитан файл `/etc/shadow`. |
| 5. Изучение механизма sudo | Изменение системного времени | В `/etc/sudoers` для пользователя `user1` добавлено разрешение `user1 ALL=(root) /usr/bin/date`. Корректность конфигурации проверена с помощью `visudo`. От имени `user1` команда `/usr/bin/date` была запущена через `sudo`, после чего системное время было успешно изменено. |
